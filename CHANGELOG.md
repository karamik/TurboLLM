# Changelog

All notable changes to TurboLLM will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [Unreleased]

### Added
- Начальная поддержка FP8 квантизации весов и KV‑кэша.
- Chunked prefill для мгновенного первого токена на длинных промптах.
- Continuous batching для максимальной утилизации GPU.
- Мониторинг через Prometheus и готовые дашборды Grafana.
- Проприетарные модули (балансировщик, кэш промптов, фильтрация данных, админ‑панель).
- Docker-образ с оптимизированным окружением (CUDA 12.2 + vLLM).
- Makefile с удобными командами для разработки и деплоя.
- Модульные тесты для API-эндпоинтов.

### Changed
- Переход с Hugging Face стандартной загрузки на vLLM (PagedAttention).
- Оптимизация использования памяти: FP8 веса + FP8 KV‑кэш.

### Fixed
- Исправлены падения (OOM) при обработке документов > 20k токенов.

### Security
- Добавлен модуль фильтрации конфиденциальных данных (PII, коммерческая тайна).

---

## [1.0.0] – 2026-08-21

### Added
- Первый публичный релиз TurboLLM.
- Поддержка моделей до 70B параметров.
- REST API для генерации (синхронной и потоковой).
- Интеграция с vLLM версии 0.4.0.
- Базовый мониторинг и логирование.
- Документация (README, примеры использования).

### Known Issues
- FP8‑квантизация требует GPU поколения Ada Lovelace / Hopper.
- Преобразование весов в FP8 выполняется через внешние утилиты (в планах встроить автоматический конвертер).

---

## [0.5.0] – 2026-07-15 (pre‑release, internal)

### Added
- Прототип на базе vLLM и HF Transformers.
- Экспериментальная поддержка длинного контекста (до 16k токенов).

---

## [0.1.0] – 2026-06-01 (internal alpha)

### Added
- Начальный концепт: оптимизация инференса через FP16 и PagedAttention.
- Базовый API без мониторинга.
